# aic8800

Unofficial fork of [radxa-pkg/aic8800](https://github.com/radxa-pkg/aic8800), not affiliated with Radxa. It adds fixes for AIC8800 USB adapters on other distributions (e.g. Armbian).

[![Release](https://github.com/LibreQ1Pro/aic8800/actions/workflows/release.yaml/badge.svg)](https://github.com/LibreQ1Pro/aic8800/actions/workflows/release.yaml)

## Build

1. `git clone --recurse-submodules https://github.com/LibreQ1Pro/aic8800.git`
2. Open in [`devcontainer`](https://code.visualstudio.com/docs/devcontainers/containers)
3. `make deb`
